# KothaFinder Nepal — polished build

This is the next implementation layer over the starter project: customer/landlord UI, real multi-photo selection and Firebase Storage upload, favorites, real-time chat, FCM token registration, map search, listing moderation state, Firestore/Storage security rules, scheduled listing expiry, message/listing notifications, and a React admin moderation dashboard.

It is source-complete but still requires your Firebase/Google Maps project configuration and production credentials. No credentials are embedded.
